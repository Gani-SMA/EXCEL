# Hospital Emergency Dashboard (Excel) — README

## Overview

Hospital Emergency Dashboard is an Excel-based analytical tool designed to monitor, manage, and visualize emergency department operations in real time. It consolidates patient flow, resource utilization, and critical performance indicators into a single interactive interface.

## Objectives

* Track emergency patient admissions and discharges
* Monitor waiting times and treatment delays
* Analyze severity distribution and case types
* Optimize staff and bed allocation
* Support quick decision-making during peak hours

## Features

* Dynamic dashboard with slicers and filters
* Real-time KPIs (Patients, Wait Time, Bed Occupancy, Critical Cases)
* Visual charts (line, bar, pie, heatmaps)
* Department-wise and time-based analysis
* Automated data updates using Excel formulas and pivot tables

  
## Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Conditional Formatting
* Data Validation
* Excel Functions (IF, VLOOKUP/XLOOKUP, INDEX-MATCH, COUNTIFS, SUMIFS)

## Dataset Description

The dataset includes:

* Patient ID
* Arrival Time & Date
* Condition Severity
* Department Assigned
* Treatment Start Time
* Discharge Time
* Bed Allocation
* Staff Assigned

## How to Use

1. Open the Excel file
2. Navigate to the Dashboard sheet
3. Use slicers to filter data (date, department, severity)
4. Analyze charts and KPIs for insights
5. Update raw data sheet to refresh dashboard automatically

## Insights Generated

* Peak emergency hours and patient load trends
* Bottlenecks in treatment or admission
* Resource shortages (beds/staff)
* High-risk patient patterns

## Limitations

* Depends on manual or static data input
* Not connected to real-time hospital systems
* Limited scalability compared to database-driven tools

## Future Improvements

* Integration with live hospital databases
* Automation using Power Query / VBA
* Predictive analytics for patient inflow
* Advanced visualization using Power BI

## Conclusion

This dashboard provides a structured and efficient way to monitor emergency operations, enabling better resource management and faster response during critical situations.
